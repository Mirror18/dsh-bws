# 凭证金库

设置 → 内置插件 → **凭证金库**。本地加密存凭证，索引随 git 同步到自己的两个远端。

## 它做什么

- 列出金库里的条目：键名、分组、备注、更新时间、值长度（**不含值**）。
- **显示值**：点一下取一次明文，20 秒后自动隐藏；不缓存、不落盘。
- **新建 / 编辑 / 删除**：值经 HTTPS 同源 POST 送到 Host，落盘前加密。
- **分组与授权**：通用层（全员可读写）/ 项目层（仅授权工作区），按 分组 × 工作区 授权。
- **试运行**：把某个分组的凭证注入环境变量，跑一条命令，回显 exit/stdout/stderr。
- **同步**：填 GitHub/Gitee 仓库 URL，推送/拉取；首次从空库拉取会自动采用远端金库的盐。
- **从 bws 迁移**：一次性把 Bitwarden Secrets Manager 的条目搬进来。

## 密钥怎么来

口令 `scrypt(N=32768,r=8,p=1)` 派生 32 字节密钥，`AES-256-GCM` 加密每条值。口令与派生密钥都不落盘；盐存在金库里（并随仓库同步），所以**同一口令 = 同一把密钥**，换机器只要拉仓库再解锁。

解锁状态只活在 dsh-web 进程内存里，重启后需要重新解锁。

## Agent 工具

`bws_list`（元数据）与 `bws_run`（注入环境变量后跑命令）由 Host 注册进会话，走面板里同一份授权矩阵。**没有「把值读给模型」的工具**——明文不进会话记录是设计约束，不是遗漏。

## 明文出现在哪

三个地方，都是单次、可控的：

1. 点「显示值」时的那一次 HTTP 响应（浏览器的 DOM 里，20 秒后消失）。
2. `dsh-bws run` 注入的子进程环境变量。
3. 新建/编辑时从浏览器到 Host 的那一次请求体。

不进日志、不进会话记录、不进 argv（所以进程表里看不到值）。

## 安全边界

- 路由在 `/bws` 前缀下，校验 loopback Host（防 DNS rebinding），写操作还要求 `x-dsh-bws: 1` 自定义头（触发 CORS 预检，跨站页面伪造不了）。
- 所有响应 `no-store`。
- 金库目录 `0700`，`vault.db` 与 `.enc` 文件 `0600`。
- 同机任何进程在被解锁期间都能调 `/bws` 取值——这是单用户机器的假设，不是多租户隔离。
- git 只存密文；历史提交抹不掉，删条目 ≠ 吊销凭证，要真正作废须轮换上游密钥。
